# zenth-social-assets

Public images for ZENTH and SparkleDomain social media posts. Metricool reads them from here when it publishes.

- `sparkledomain/<campaign>/` and `zenth/<campaign>/`: one file per image, named after the post (`p01_intro.png`, `p05_three_checks_2.png`).
- Only finished, approved-to-be-public post images go here. Nothing private.
